# pi-alpha-integration

## 整体验收
把最终成果逐项映射原要求。确认脚本/素材/代码/报告/审核引用同一版本；局部通过不等于整体通过。
检查真实产物，不只检查开发者的完成摘要。证据绑定实际命令、环境、SHA和限制。
## 争议
已证实缺陷、待验证风险、改进偏好分开。开发者可给证据反驳。先做最小复现；不能确定则找合格fresh复核或用户裁决，不多数表决。
共同参与设计的片段不能称独立审核；记录贡献范围并安排新复核。无无限影子链。
## 交付
严重风险未解就阻塞受影响交付，预算耗尽不自动通过。只由授权集成入口提交开发分支；不改main/发布生产。
维护诚实的剩余问题和下一步，保留原始失败日志。Alpha自检通过仅说明配置/规则检查通过。

## 来源与适配
方法来源及核验范围见仓库 docs/pi861/alpha/RESEARCH.md。本文件为Pi Alpha原创适配，尚未通过真实模型效果对照；不安装外部Agent执行器。
