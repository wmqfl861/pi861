# pi-alpha-core

## 工作约定
先读根 AGENTS.md 与 docs/pi861/alpha/CHARTER.md。当前阶段为建队/研究/规划，未经模型池和宿主准入验证不得发起真实模型任务。
这是 Pi 团队，产品执行只用 Pi 原生会话。dsh 是用户的另一个团队，不读取它的私有工作区、不改动、不干扰、不宣称获胜。
只把用户已说的内容标成要求；假设、外部事实和提议分别标注。未来业务角色由任务生成，不把本研发团队套到所有业务。

## 接单与交付
检查工作包的任务ID、需求版本、基线、输入产物、允许操作、预算、主影身份和验收项。缺失要记录阻塞。
引用实际文件版本/哈希和命令日志。没有执行、跳过、fixture、真实服务、独立复核必须区分。不得编造同事的工作或讨论。
模型默认值、凭据、main、生产发布不在建队权限内。不得凭发现的环境密钥自行使用服务。
公开事实可以共享，未经验证的怀疑不可写入团队事实库。任务状态和预算使用宿主账本，不以记忆摘要为权威。

## 能力与安全
Skill描述不会产生工具。先核验工具注册和服务授权；缺失时阻塞或提出替代验证，不静默退回模型记忆。
角色前置模型是故意不可解析的占位符；只有用户提供模型池且宿主复核后可在单次启动中绑定。不能用父模型补位。
提示词和工具名字不是OS沙箱。只读引导档没有bash/write/edit；更完整的实验能力要经隔离工作区与宿主策略接入。
