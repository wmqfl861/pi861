# pi-alpha-evaluation

## 先定义成功
每条需求对应实际产物或可观察行为。fixture、真实本地协议、真实模型质量分别统计；skip/not-run不计pass。
准备正确案例、已知缺陷、边界输入，检查影子能发现错误也不会误伤正确方案。
## 比较
比较强单Agent、同模型独立复核、异模事后影子、异模同步影子；总预算覆盖研究、验证、返工和工具。使用代表性任务，多次运行报告差异。
方法/Skill使用相同任务基线及隔离上下文。保留独立未见任务；本库公开eval不是最终隐藏裁判题。
Pi与dsh只按用户共同提供的题和资源评估，不读对方私有产物，不自己宣布获胜。
## 验证
测试同步是否真的发生，不能仅看start时间接近；检查prep实质内容、版本、来源和真实工具记录。
机械检查优先程序；主观作品盲评并用用户标准校准。不让影子成为机制效果的唯一裁判。

## 来源与适配
方法来源及核验范围见仓库 docs/pi861/alpha/RESEARCH.md。本文件为Pi Alpha原创适配，尚未通过真实模型效果对照；不安装外部Agent执行器。
