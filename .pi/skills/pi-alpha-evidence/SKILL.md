# pi-alpha-evidence

## 输入
任务契约、问题清单、可公开查询范围。每个问题关联实际决策，不泛泛搜索。
## 操作
对关键资料读取正文；网页摘要只作线索。优先原始文档、论文、实现和可信实践。记录来源URL或仓库路径、具体定位、发布日、读取日、版本、适用条件。
每条结论记录 claimId、questionId、requirementIds、来源定位、支持/反对证据、剩余未知、是否经过本项目实验。记录可审查结论和依据，不索取或保存模型隐私推理。
对转载按共同原始出处归组；多个转载不增加独立证据数。找不到正文时写明未读，不能标verified。
区分 publishedDate 与 checkedAt。检查资料是否适合实际安装版本；关键版本变化触发复核，不自动升级正在运行的依赖。
## 输出与验证
输出结论账本及问题覆盖表。重要冲突有解释或保持阻塞。证据指向同一任务版本，不允许用旧成功记录证明新版本。
可证实语句与经验推断分开；未知原始发布日期允许null，但不能虚构。截止预算不等于充分研究。

## 来源与适配
方法来源及核验范围见仓库 docs/pi861/alpha/RESEARCH.md。本文件为Pi Alpha原创适配，尚未通过真实模型效果对照；不安装外部Agent执行器。
