# 阿尔法bootstrap自我质疑记录

作者：当前创建团队的助手会话。类型：author-self-review。独立异模评审：未执行。
目标：主动检查设计盲点，不能以自我签字代替影子工作证据。

## 本轮发现及处理
SR01 “14个角色=14个Agent已经运行”：错误。team/status明确configured-unarmed、realAgentsStarted=0，无网络或模型启动入口。
SR02 未配模型会继承父模型，破坏异模：角色默认固定alpha-unconfigured/awaiting-model-pool占位；prepare要求用户批准模型池、实际模型不同与明确预算。
SR03 工具存在于父会话即可使用：错误。每角色显式child-only web扩展；固定插件host测试检查注册，服务能力仍单列待验证。
SR04 缺Skill只有warning：项目check要求每个指定Skill文件存在，固定解析器再次resolveSkills，缺失失败。
SR05 “写了同步规则”=真实同步：错误。protocol simulator仅是未来适配契约，真实两槽准入、事件/预警通道和资源隔离仍是A5。
SR06 把布尔字段当专业证据：researchGate只做元数据完整性过滤，所有通过仍eligible-for-independent-review，不叫已证实。
SR07 影子复制全权限：引导档无shell/write/edit；实验完整能力需要独立沙箱和可信宿主，角色工具白名单不是OS边界。
SR08 把专业模板直接当通用业务团队：本团队是研发团队；未来业务角色由用户目标生成，视频仅示例。
SR09 自研Skill自评过关直接推广：当前11技能标原创适配、效果未校准；实验/评估要求基线、反例和未见任务。
SR10 竞争压力导致自封胜利：与dsh隔离，最终公共任务/隐藏题及裁判由用户控制，全部成本记录。
SR11 过度框架化：仅新增bootstrap资产与开发工具，不改产品runtime或建立第二套调度器；保留现有Pi状态/预算接入工作。
SR12 历史验收被本轮覆盖：保留R1–R8/AX1–AX10和CLOUD-OPEN-1/2，不将新配置检查冒充产品通过。

## 仍然需要实测
模型池和单次授权、真实模型能力校准、异模互补性、同时深度研究是否改善质量、影子误报漏报、OS/网络/账户隔离、共享预算、持久状态与中断恢复。
角色前置模型、独立上下文和字段检查不能防止可信操作者主动绕过启动方案；本工具不是不可绕过的安全边界。
meta gate无法证明来源真的支持结论，需要实际抓取证据、语义检查和独立评审。占位模型阻止默认误用，不等于所有调用路径都有Alpha准入。

## 校验器实现后的追加自查
SR13 JavaScript正则可能把undefined强制转成字符串：显式要求非空字符串ID，添加缺模型ID反例。
SR14 任意嵌套模型字段可能携带未审查配置：改为模型元数据字段白名单；未知字段拒绝，模板无凭据。
SR15 缺methodAvailable不应被当“有方法”：要求明确布尔值，缺失即失败；自称实验成功但无产物仍needs-experiment。
SR16 准备记录与来源字段均可被伪造：验证器明确只筛结构，真实工具证明、签发身份/时间和语义核验留给宿主接入；不声称纯函数是安全闸。
