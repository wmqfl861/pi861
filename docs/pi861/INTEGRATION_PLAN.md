# Pi861 第二阶段：真实运行链路集成

基线：e539452d2cd895c78b8fd4846e243e53e7dc1265。范围继承 IMPLEMENTATION_PLAN.md 的 R1–R8，不降低原验收条件。

## 本轮工作流

按可独立实现的模块推进，集成后共同验收。不声称当前开发环境已经启动多台开发 Agent。

1. Skill/MCP：磁盘原始包归档、候选与发布、分层目录、绑定校验；真实 stdio / HTTP MCP 客户端；Pi 工具激活、撤权和元数据变化检测。安装源视为不可信数据，不运行其脚本。
2. 记忆：跨会话持久层、分页和增量、带来源版本的自动提炼与摘要、撤回传播；扩展 PostgreSQL 接口及真实数据库集成测试。派生摘要不能代替执行台账。
3. 模型：连接真实 Pi 模型请求，入口分类及运行中升级、故障接管与恢复探测；所有尝试有界，原始工具结果保留，取消不触发新工作。
4. 执行：实际 Pi RPC 子进程、独立 Git worktree、持久任务图与事件驱动补位；验证与集成独立；建立远程执行协议而不是共享文件。
5. Goal/搜索：目标入口接入实际执行器；网页读取与结果分页；继续使用统一权限、预算和取消。

## 集成原则

- 唯一的任务/模型执行权，唯一的记忆权威存储；不同时启用多个自动续跑器。
- 原始 Skill 默认不进入模型提示；发布版和具体分支/阶段决定实际工具集。
- 危险操作不因重试、路由或恢复自动重放；未知结果必须核对。
- 自动生成的经验保持候选身份，发布、授权和验收由可信控制面执行。
- 稳定项目标识，不使用不同节点的目录路径来判断项目身份。
- 配置不包含真实密钥；测试不调用付费模型或用户业务数据库。
- PostgreSQL 凭据只给可信服务，不交给模型；关闭数据库时不创建另一份共享真相。
